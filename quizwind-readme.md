# WindWave Quiz

Practicum site for developing an interactive component (a quiz) with JavaScript, themed on wind energy for smart cities.

## Features
- 8 shuffled questions, each with options A to D (the first is "In web design, what does CSS stand for?")
- Progress bar, live score and a 20-second timer per question
- Instant feedback with an explanation, keyboard support (A-D to answer, Enter for next)
- Result screen with score ring, rank, saved best score and answer review

## Files
- `quizwind-page.html` – the page
- `quizwind-style.css` – sunrise styles and animations
- `quizwind-script.js` – question bank, event handling, DOM updates, scoring
- `vercel.json` – opens the page at the site root (keep this exact name)

## Upload to GitHub
1. Create a NEW repository for this site.
2. Add file -> Upload files, drag in the unzipped files (not the zip), and commit.

## Deploy on Vercel
1. Vercel -> Add New -> Project, import the repository.
2. Framework Preset: Other. Leave build settings empty. Deploy.
